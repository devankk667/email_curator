Settings & Sync

Manage Gmail sync, model retraining, and app configuration.

Gmail Sync

Fetch your latest emails from Gmail Primary inbox via the Gmail API (read-only).

OAuth2 Setup Steps:

  • 1Create a project at Google Cloud Console and enable the Gmail API.
  • 2Create OAuth credentials (Desktop App type), download the JSON, and rename it to credentials.json.
  • 3Place credentials.json in the email_generator/ folder, then click Sync.

Retrain AI Model

Improve classification accuracy by retraining on your real Gmail emails combined with the SpamAssassin corpus. Takes 1–3 minutes.

Groq LLM API (Optional)

Add a Groq API key to unlock advanced LLM-powered answers in the Assistant. Without it, answers use local extractive search.

Set GROQ_API_KEY=your_key in a .env file next to dashboard_server.py, then restart the server.
